## ✨ What is GitSearch?

**GitSearch Mobile** is a pocket GitHub companion for Android that turns the raw, slow, login-first web into a beautiful, instant, and completely private discovery experience.

- 🔍 **Search all of GitHub instantly** — no account, no login, no waiting
- 🔥 **A discovery home** — For You feed, Pick Your Vibe, Project Threads with comments, Suggestion cards and curated categories, ready before you even type
- 💬 **Live discussions** — every project thread carries its real GitHub discussions & comments, readable right from the home screen
- 📖 **Read any README** in a gorgeous reader mode — right inside the app, even offline after caching
- 📥 **In-app updates** — downloads run inside the app with a live progress bar, then install on their own
- 🕶️ **Six animated dark themes** you can switch live, from AMOLED black to Cyberpunk Neon
- 🔐 **Lock it down** with a 4-digit PIN or your fingerprint/face — like a vault for your repos
- 💬 **Peer-to-peer GitChat** — share repos with people around you, no server in between
- 🔔 **Smart new-project alerts** — follow any developer and the bell rings the moment they drop a new repo

> One APK. ~6.9 MB. No sign-up. No server. No tracking. Ever.

<br/>

Let's be honest about how exploring GitHub feels on a phone today:

| 😩 The pain | ❌ The official app | ❌ The mobile browser | **✅ GitSearch** |

| **"I just want to search, not sign in"** | Requires a GitHub account | Works, but heavy and slow | **Instant, zero login** |

**GitSearch exists so you can discover, read, bookmark, and share GitHub — the way a great product should feel: instant, private, and beautiful.** No account. No tracking. No middleman.

## 🗺️ A Tour of Every Screen

GitSearch is built around five tabs plus a floating search bar. Here's exactly what lives in each one.

### 🏠 Home — the Discovery Hub
The moment you open the app you land on a personalized discovery surface — no typing required. It's made of stacked "strips", each with its own job:

| Strip | What it does |
|---|---|
| **For You** | A smart feed mixed from GitHub trending, your top searches and surprise picks. Every card teaches the feed: **👍** = "more like this", **👎** = "less like this" |
| **Pick Your Vibe** | A big swipeable card (👍 / 👎) that jump-starts personalization before you've even searched once |
| **Project Threads** | Big repo cards showing the README overview **plus live discussions & comments** pulled from the repo's GitHub issues. Tap a comment → read the whole thread. Tap "View all discussions" → browse every discussion |
| **Continue Reading** | Your recently opened repos, one tap away — tap any card to jump straight back into its README |
| **Suggestion Cards** | Smart recommendations built from your search history. The big card shows your position (1/12) — swipe through the deck or tap a "Recently shown" mini card |
| **🔥 Trending** | This week's hottest repos across GitHub |
| **Categories** | 10 quick jumps: AI/ML, Web Dev, Rust, APIs, Python, Mobile, Games, Security, DevOps & more |

Every card anywhere in the app opens its **README reader sheet**, and every card carries quick actions: **🔖 bookmark**, **💬 send to GitChat**, **➕ follow the developer**.

### 🔍 Search — the Fast Lane
- **Smart suggestions** — type and your search history appears inline, with one-tap delete
- **Sort & filter** — by ⭐ stars, 🍴 forks, or 🕐 recently updated
- **Infinite scroll** — results keep loading as you scroll; no paging
- **Results per page** — 15 / 30 / 50, your call
- **Rich result cards** — language dots, topic tags and license badges at a glance

### 🔖 Saved — your private library
- **Bookmarks** — save any repo permanently on-device. No account, all private, with an animated badge counter
- **Achievements** — daily streaks and badges for the way you use the app
- **Home-screen widget** — one-tap Trending right from your launcher

### ➕ Following — the bell system
- Follow any developer anywhere with one tap (**➕**), and GitSearch watches their profile
- The **🔔 bell** rings (unread badge + phone notification) whenever a followed developer releases a new project
- Your follows are saved locally; a background scan checks every 15 minutes, and you can hit **"Check now"** in the notification sheet anytime
- Notification permission is requested the first time you follow someone — and the app tells you exactly where to re-enable it if you ever block it

### 💬 GitChat — peer-to-peer sharing
- Share any repo (from the feed, threads or results) straight into GitChat
- Broadcast and receive repo links with nearby devices — **no server, no relay, no account**

### 👤 Profile — your GitHub identity
- Enter your username once: avatar, bio, repo list, followers & following
- Your **Profile README** renders live, refreshed with pull-to-refresh
- Tap any repo to read its README in-app; switch profiles with one tap

## 🔔 Self-Updating

Every release is **pushed straight to this repository** and the app detects it — no store, no approval queue, no middleman.

- Flashing alert on the update button the moment a new version is found
- Rich notification with the version + first change; tap to install

## ⚙️ Build From Source

> **Prerequisites:** Node.js 18+, JDK 17+, Android Studio + Android SDK

```bash
# Clone
git clone https://github.com/YOUR_USERNAME/GitSearch-Mobile.git
cd GitSearch-Mobile

npm install          # install dependencies
npm run dev          # preview in the browser

npm run build        # build the web bundle
npx cap sync android # sync to the native project
cd android
.\gradlew.bat assembleDebug   # compile the APK
# → android/app/build/outputs/apk/debug/app-debug.apk
```

## ❓ FAQ

<details>
<summary><strong>Do I really not need an account?</strong></summary>
<br/>
Correct. Search, browse, read READMEs, bookmark, share and chat — all without any GitHub account. The public API needs none for search.
</details>

<details>
<summary><strong>Is it actually private?</strong></summary>
<br/>
Yes. The APK contains no analytics SDK. All data lives in your device storage. The only network calls are yours, to GitHub's public API.
</details>

<details>
<summary><strong>How do the notifications work?</strong></summary>
<br/>
When you follow a developer, GitSearch remembers their profile and periodically checks for new repos. The moment a new project appears, a notification is scheduled on your phone and the bell badge in the app shows an unread count. Everything is local — your follows never leave your device.
</details>

<details>
<summary><strong>Why don't I get notifications even though I followed someone?</strong></summary>
<br/>
Android needs notification permission for alerts. The first time you follow someone the app asks for it — if you denied it, go to your phone's **Settings → Apps → GitSearch → Notifications** and allow them. The app also warns you about exactly this when you follow.
</details>

<details>
<summary><strong>How do updates work without the Play Store?</strong></summary>
<br/>
The app reads this repository's release feed. When a new tag appears it notifies you (rich notification). Tap **Download & install** and the APK downloads right inside the app with a live progress bar, then installs on its own. It cross-checks with the release page so it never misses an update.
</details>

<details>
<summary><strong>Why isn't this on the Play Store?</strong></summary>
<br/>
A GitHub-focused app doesn't need a store queue between you and the next improvement. Direct releases mean faster updates, no approval lag, and total control — for us *and* for you.
</details>

<details>
<summary><strong>How do I update once installed?</strong></summary>
<br/>
Tap the pulsing update indicator in the app, or go to the **Updates** screen and hit "Check for updates". GitSearch will confirm the latest version, download it **inside the app** with a progress bar, and install it in one tap.
</details>

<details>
<summary><strong>How does the For You feed learn?</strong></summary>
<br/>
It mixes GitHub's trending repos with your own activity — what you search for, open, bookmark and rate with 👍 / 👎. Everything is computed on your device, so the feed is personal *and* private. "Reset feed" in Settings starts fresh.
</details>

<details>
<summary><strong>What are Project Threads exactly?</strong></summary>
<br/>
They're repo cards with a soul: each one shows the README overview plus the repository's **live GitHub discussions and comments** (loaded from its issues). You can read conversations without leaving the home screen, and open the real thread on GitHub to reply.
</details>

<details>
<summary><strong>Can I use this without internet?</strong></summary>
<br/>
Reading a cached README works offline, and your bookmarks, history and settings always do. Live data (search, feeds, threads) obviously needs a connection to GitHub.
</details>

<details>
<summary><strong>Is there an iOS version?</strong></summary>
<br/>
Not yet. GitSearch is currently an Android app — that's where the built-in update system, widget and deep system integration shine.
</details>
